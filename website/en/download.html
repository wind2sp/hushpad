Installation

  1. Download the zip file and extract it wherever you like (for example C:\Program Files\Hushpad or your Documents folder).
  2. Run Hushpad.exe. There's no installer.
  3. On first launch, choose a folder for your notes and set a password. To use Hushpad on several PCs, pick a folder inside Dropbox or OneDrive.

If you see “Windows protected your PC”

Because Hushpad is new, Windows SmartScreen may show a warning. Check that your download matches the SHA-256 value below, then click “More info › Run anyway.”

Verify the file (SHA-256)

In PowerShell, compare this value with the output of Get-FileHash .\filename.zip.

Shown at release

System requirements

Windows 10 (version 2004 or later) or Windows 11, 64-bit. Hiding the window from capture needs Windows 10 version 2004 or later. No internet connection required.

Uninstalling

Just delete the program folder. Your notes stay in the vault folder, still encrypted. To remove the notes as well, delete the vault folder too.

Hushpad

Write quietly. Seen by no one. A Windows notepad that saves as you type and encrypts every note.

hush (as in “shh”) + pad (a notepad): a notepad that keeps quiet about what you write.
