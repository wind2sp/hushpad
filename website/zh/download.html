安装

  1. 下载 zip 文件，解压到任意位置（例如 C:\Program Files\Hushpad 或“文档”文件夹）。
  2. 运行 Hushpad.exe，无需安装。
  3. 首次运行时，选择存放笔记的文件夹并设置密码。如需在多台电脑上使用，请选择 Dropbox 或 OneDrive 中的文件夹。

如果出现“Windows 已保护你的电脑”

由于是新发布的程序，Windows SmartScreen 可能会发出警告。请先确认下载的文件与下方 SHA-256 值一致，再点击“更多信息 › 仍要运行”。

校验文件（SHA-256）

在 PowerShell 中运行 Get-FileHash .\文件名.zip，将结果与此值比对。

系统要求

Windows 10（版本 2004 及以上）或 Windows 11，64 位。在截图中隐藏窗口需要 Windows 10 版本 2004 及以上。无需联网。

卸载

删除程序文件夹即可。笔记仍保留在存储文件夹中（保持加密）。如需一并删除笔记，请同时删除存储文件夹。

Hushpad

安静记录，无人可见。一款不用手动保存、所有笔记都加密存放的 Windows 记事本。

hush（嘘，安静）+ pad（记事本），意为安静记录的私密记事本。
