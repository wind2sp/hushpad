## 제품 이름
Hushpad

## 간단한 설명 (Short description)
쓰는 즉시 저장되고 모든 메모가 암호화되는 메모장입니다. Windows에서는 스크린샷과 화면 공유에 창이 보이지 않습니다. 계정도 서버도 없는 무료 오픈소스입니다.

## 설명 (Description)
Hushpad는 메모장 탭에 흩어 두던 기록을 한곳에 조용히 모아 두는 메모장입니다. 회의 메모, 붙여 넣기 전에 잠깐 둘 글, API 키와 JSON, 스크린샷과 짧은 화면 녹화까지 담을 수 있습니다.

저장 버튼이 없습니다. 쓰는 즉시 저장되고, 컴퓨터를 다시 켜도 메모와 열어 둔 탭이 그대로입니다.

모든 메모는 AES-256-GCM으로 암호화된 파일로만 저장됩니다. 다른 프로그램이나 클라우드가 보관 폴더를 읽어도 내용은 알 수 없습니다. 암호는 이 PC에서 처음 한 번만 넣으면 됩니다.

Hushpad 창은 다른 프로그램의 스크린샷, 화면 녹화, 화면 공유에 찍히지 않습니다. 회의에서 화면을 공유하는 동안 메모를 열어 두어도 상대에게는 보이지 않습니다.

메모는 두 가지입니다.
• 서식 메모: 웹이나 문서에서 복사한 내용을 서식 그대로 붙이고, 이미지와 스크린샷, 짧은 화면 녹화를 넣습니다.
• 코드 메모: HTML, JSON, 설정 값, API 키를 줄 번호와 색 구분으로 봅니다. JSON 정리도 됩니다.

그 밖에
• 복사한 내용은 Windows 클립보드 기록(Win+V)과 클라우드 클립보드에 남지 않습니다.
• 비밀 메모는 열 때마다 가려져 있고, 복사하면 30초 뒤 클립보드를 비웁니다.
• Ctrl+K 하나로 메모와 명령을 찾아 실행합니다.
• 어디서든 Ctrl+Alt+N 새 메모, Ctrl+Alt+M 클립보드를 메모로, Ctrl+Alt+S 스크린샷.
• 자리를 비우거나 Windows를 잠그면 Hushpad도 함께 잠글 수 있습니다.
• 보관 폴더를 OneDrive나 Dropbox 안에 두면 여러 PC에서 같은 메모를 씁니다.
• 화면 언어: 한국어, English, 日本語, 简体中文

계정을 만들 필요가 없고, Hushpad 서버도 없으며, 사용 기록을 어디에도 보내지 않습니다. 메모는 사용자가 고른 폴더에만 있습니다.

Windows를 켜면 트레이에서 조용히 시작합니다. 원하지 않으면 설정 › 앱 › 시작 프로그램에서 끌 수 있습니다. 앱을 제거해도 보관 폴더의 메모는 지워지지 않습니다.

무료 오픈소스(GPL-3.0-or-later)입니다. 소스 코드: https://github.com/wind2sp/hushpad

암호를 잊으면 누구도 메모를 되살릴 수 없습니다. 암호는 따로 잘 적어 두세요.

## 이번 버전의 새로운 기능 (What's new in this version)
Microsoft Store에 처음 올리는 버전입니다. 홈페이지에서 받는 1.0.0과 기능은 같고, Windows를 켤 때 실행하는 설정을 Windows 설정 › 앱 › 시작 프로그램에서 켜고 끕니다.

## 제품 기능 (Product features, 8개)
1. 쓰는 즉시 자동 저장, 다시 켜도 메모와 탭이 그대로
2. 모든 메모를 AES-256-GCM으로 암호화해 저장
3. 스크린샷·화면 녹화·화면 공유에 창이 보이지 않음
4. 서식 메모(이미지·스크린샷·짧은 녹화)와 코드 메모(HTML·JSON·키)
5. Windows 클립보드 기록에 남지 않는 복사, 비밀 메모 가림막
6. Ctrl+K로 메모와 명령 찾기, 어디서든 쓰는 단축키
7. 계정·서버·사용 기록 전송 없음
8. 한국어·영어·일본어·중국어(간체) 화면
