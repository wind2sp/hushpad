現在、正式版を準備しています。公開されたらこのページから直接ダウンロードでき、アドレスも変わりません。

アプリは日本語・英語・韓国語・簡体字中国語に対応しています。言語は［表示］›［言語］でいつでも切り替えられます。

インストール

  1. zip ファイルをダウンロードし、好きな場所（例：C:\Program Files\Hushpad やドキュメントフォルダー）に展開します。
  2. Hushpad.exe を実行します。インストール作業は必要ありません。
  3. 初回起動時に、メモを保管するフォルダーとパスワードを決めます。複数の PC で使う場合は、Dropbox や OneDrive 内のフォルダーを選んでください。

「Windows によって PC が保護されました」と表示されたら

新しいアプリのため、Windows SmartScreen が警告を表示することがあります。ダウンロードしたファイルが下の SHA-256 値と一致することを確認してから、「詳細情報 › 実行」をクリックしてください。

ファイルの確認（SHA-256）

PowerShell で Get-FileHash .\ファイル名.zip を実行し、表示された値と比べてください。

動作環境

Windows 10（バージョン 2004 以降）または Windows 11、64 ビット。キャプチャからウィンドウを隠す機能は Windows 10 バージョン 2004 以降で動作します。インターネット接続は不要です。

アンインストール

プログラムのフォルダーを削除するだけです。メモは保管フォルダーにそのまま残ります（暗号化された状態）。メモも消す場合は、保管フォルダーも一緒に削除してください。

Hushpad

静かに書いて、誰にも見せない。保存ボタンなしで自動保存し、すべてのメモを暗号化する Windows 用メモ帳です。

hush（しーっ、静かに）＋ pad（メモ帳）。静かに書き留めておく、秘密のメモ帳という意味です。
