The app comes in Korean, English, Japanese and Simplified Chinese, and starts in your system language. Switch anytime under Menu (⋯) › View › Language.

First run on Windows

  1. Download the zip file and extract it wherever you like (your Documents folder, for example). There's no installer.
  2. Open the extracted Hushpad folder and run Hushpad.exe.
  3. If “Windows protected your PC” appears, click “More info › Run anyway.” Hushpad isn't code-signed yet, so SmartScreen may warn you about it. If you'd like to be sure first, check the SHA-256 value as described below.
  4. Choose a folder for your notes and set a password. To use Hushpad on several PCs, pick a folder inside Dropbox or OneDrive.

First run on a Mac

  1. Download and unzip the file, then move Hushpad.app to your Applications folder.
  2. The first time, right-click (or Control-click) Hushpad.app in Finder, choose “Open,” then click “Open” again in the warning. The app isn't signed or notarized by Apple, so double-clicking won't open it. If you don't see an Open button, go to System Settings › Privacy & Security and click “Open Anyway.”
  3. The first time you take a screenshot or record your screen, macOS asks for Screen Recording permission. Turn on Hushpad under System Settings › Privacy & Security › Screen & System Audio Recording (Screen Recording on macOS 14 and earlier), then restart the app.
  4. Choose a folder for your notes and set a password. The system-wide shortcuts are ⌃⌥N (new note), ⌃⌥M (clipboard to note), ⌃⌥S (screenshot) and ⌃⌥R (screen recording).

Starts automatically

After the first run, Hushpad starts in the tray when Windows starts (on a Mac, in the menu bar when you log in). Notes are encrypted and saved as you type, so they're still there after a restart. You can turn auto-start off from the tray or menu bar icon's menu, or from the Security menu.

System requirements

  • Windows: Windows 10 (version 2004 or later) or Windows 11, 64-bit. Hiding the window from capture needs Windows 10 version 2004 or later.
  • Mac: a Mac with Apple silicon (M1 or later). There is no build for Intel-based Macs.
  • No internet connection required.

Verify the file (SHA-256)

Compare your download with the SHA-256 value shown above. On Windows, run Get-FileHash .\Hushpad-win64.zip in PowerShell. On a Mac, run shasum -a 256 Hushpad-macos-arm64.zip in Terminal.

Uninstalling

If auto-start is on, turn it off from the tray or menu bar icon first, then delete the program folder (Hushpad.app on a Mac). Your notes stay in the vault folder, still encrypted. To remove the notes as well, delete the vault folder too.

Hushpad

Write quietly. Seen by no one. A notepad for Windows and Mac that saves as you type and encrypts every note.

hush (as in “shh”) + pad (a notepad): a notepad that keeps quiet about what you write.
