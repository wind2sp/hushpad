# Store 商店信息 — 简体中文 (zh-CN)

## 产品名称
Hushpad

## 简短说明 (Short description)
边写边自动保存、每条笔记都加密的记事本。在 Windows 上，它的窗口不会出现在截图和屏幕共享中。无需账户，没有服务器，免费开源。

## 说明 (Description)
Hushpad 把平时散落在记事本标签页里的内容安静地收在一处：会议记录、粘贴前临时放一下的文字、API 密钥和 JSON，还有截图和简短的录屏。

没有保存按钮。输入时自动保存，重启电脑后笔记和打开的标签页都还在。

所有笔记都只以 AES-256-GCM 加密后的文件保存。其他程序或云盘即使读取保管文件夹，也看不到内容。每台电脑只需第一次输入密码。

Hushpad 的窗口不会出现在其他程序的截图、录屏和屏幕共享中。开会共享屏幕时开着笔记，对方也看不到。

• 富文本笔记：从网页或文档复制的内容保留格式粘贴，还能放入图片、截图和简短录屏。
• 代码笔记：HTML、JSON、配置值和 API 密钥带行号和语法着色显示，也能整理 JSON。
• 复制的内容不会留在 Windows 剪贴板历史记录（Win+V）中。
• 私密笔记每次打开时都会遮住，复制后 30 秒自动清空剪贴板。
• 按 Ctrl+K 即可查找笔记和命令。
• 界面语言：简体中文、한국어、English、日本語

无需注册账户，没有 Hushpad 服务器，也不会发送任何使用数据。Windows 启动时会在托盘中安静运行（可在“设置 › 应用 › 启动”中关闭）。

基于 GPL-3.0-or-later 的免费开源软件。源代码：https://github.com/wind2sp/hushpad

忘记密码后，任何人都无法恢复笔记。

## 此版本的新增功能
首次在 Microsoft Store 发布。功能与官网 1.0.0 版相同，开机启动在“设置 › 应用 › 启动”中开启或关闭。

## 产品功能（8 条）
1. 输入时自动保存，重启后笔记和标签页仍在
2. 所有笔记以 AES-256-GCM 加密保存
3. 窗口不会出现在截图、录屏和屏幕共享中
4. 富文本笔记（图片、截图、简短录屏）
5. 代码笔记（HTML、JSON、密钥）及 JSON 整理
6. 复制内容不进剪贴板历史，私密笔记自动遮挡
7. Ctrl+K 查找笔记和命令，全局快捷键
8. 无账户、无服务器、不收集使用数据
