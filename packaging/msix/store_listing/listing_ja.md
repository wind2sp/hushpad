# Store 掲載情報 — 日本語 (ja-JP)

## 製品名
Hushpad

## 短い説明 (Short description)
入力した瞬間に保存され、すべてのメモが暗号化されるメモ帳です。Windows ではスクリーンショットや画面共有にウィンドウが映りません。アカウントもサーバーも不要な無料のオープンソースです。

## 説明 (Description)
Hushpad は、メモ帳のタブに散らばりがちな記録をひとつにまとめておくメモ帳です。会議のメモ、貼り付ける前の下書き、API キーや JSON、スクリーンショットや短い画面録画まで入れておけます。

保存ボタンはありません。入力するとすぐに保存され、再起動してもメモと開いていたタブはそのままです。

すべてのメモは AES-256-GCM で暗号化されたファイルとしてのみ保存されます。ほかのアプリやクラウドが保管フォルダーを読んでも、中身はわかりません。パスワードの入力は PC ごとに最初の一度だけです。

Hushpad のウィンドウは、ほかのアプリによるスクリーンショット、画面録画、画面共有に映りません。会議で画面を共有している間にメモを開いていても、相手には見えません。

• 書式付きメモ：Web や文書からコピーした内容を書式ごと貼り付け、画像やスクリーンショット、短い画面録画も入れられます。
• コードメモ：HTML、JSON、設定値、API キーを行番号と色分けで表示。JSON の整形もできます。
• コピーした内容は Windows のクリップボード履歴（Win+V）に残りません。
• 秘密メモは開くたびに隠れていて、コピーすると 30 秒後にクリップボードを消去します。
• Ctrl+K でメモもコマンドもすぐ見つかります。
• 表示言語：日本語、한국어、English、简体中文

アカウント登録は不要で、Hushpad のサーバーもなく、利用状況をどこにも送信しません。Windows の起動時にトレイで静かに起動します（設定 › アプリ › スタートアップ でオフにできます）。

GPL-3.0-or-later の無料オープンソースです。ソースコード：https://github.com/wind2sp/hushpad

パスワードを忘れると、誰もメモを元に戻せません。

## このバージョンの新機能
Microsoft Store での最初のリリースです。機能は Web サイト版 1.0.0 と同じで、Windows 起動時の実行は 設定 › アプリ › スタートアップ で切り替えます。

## 製品の機能（8 個）
1. 入力するとすぐ保存、再起動してもメモとタブはそのまま
2. すべてのメモを AES-256-GCM で暗号化して保存
3. スクリーンショット・画面録画・画面共有にウィンドウが映らない
4. 書式付きメモ（画像・スクリーンショット・短い録画）
5. コードメモ（HTML・JSON・キー）と JSON の整形
6. クリップボード履歴に残らないコピー、秘密メモの目隠し
7. Ctrl+K でメモとコマンドを検索、どこでも使えるショートカット
8. アカウント・サーバー・利用状況の送信なし
