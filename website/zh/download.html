在 Windows 上首次运行

如果是从 Microsoft Store 安装的，在开始菜单中打开 Hushpad 后只需完成第 4 步。便携版 zip 解压到任意位置后运行 Hushpad.exe 即可。

  1. 下载并运行 Hushpad-win64-setup.exe。无需管理员权限，会安装到你的用户文件夹。
  2. 如果出现“Windows 已保护你的电脑”，请点击“更多信息 › 仍要运行”。这是未进行代码签名的新程序，SmartScreen 可能会发出警告。如需确认，可先按下方方法核对 SHA-256。
  3. 安装完成后 Hushpad 会自动打开，之后可从开始菜单打开。有新版本时 Hushpad 会提示并自动更新。
  4. 选择保存笔记的文件夹并设置密码。如果要在多台电脑上使用，请选择 Dropbox 或 OneDrive 中的文件夹。

在 Mac 上首次打开

  1. 下载并解压 zip 文件，把 Hushpad.app 移到“应用程序”文件夹。
  2. 第一次打开时，请在访达中右键点按（或按住 Control 键点按）Hushpad.app，选择“打开”，再在警告窗口中点击“打开”。该应用未经 Apple 签名和公证，直接双击无法打开。如果没有“打开”按钮，请前往“系统设置 › 隐私与安全性”，点击“仍要打开”。
  3. 第一次截图或录屏时，macOS 会请求屏幕录制权限。请在“系统设置 › 隐私与安全性”的屏幕录制设置中打开 Hushpad，然后重新启动应用。
  4. 选择存放笔记的文件夹并设置密码。全局快捷键为 ⌃⌥N（新建笔记）、⌃⌥M（剪贴板存为笔记）、⌃⌥S（截图）和 ⌃⌥R（录屏）。

开机自动运行

首次运行后，Hushpad 会在 Windows 启动时（Mac 上为登录时）自动在托盘（Mac 上为菜单栏）中运行。笔记一边输入一边加密保存，重启电脑后依然保留。可在托盘（菜单栏）图标的菜单或“安全”菜单中关闭自动运行。

系统要求

  • Windows：Windows 10（版本 2004 及以上）或 Windows 11，64 位。在截图中隐藏窗口需要 Windows 10 版本 2004 及以上。
  • Mac：搭载 Apple 芯片（M1 及更新）的 Mac。不提供 Intel 处理器 Mac 的版本。
  • 无需联网。

校验文件（SHA-256）

请将下载文件的校验值与上方的 SHA-256 值比对。Windows 上在 PowerShell 中运行 Get-FileHash .\Hushpad-win64.zip，Mac 上在“终端”中运行 shasum -a 256 Hushpad-macos-arm64.zip。

卸载

如果是用安装程序或 Microsoft Store 安装的，请在 Windows 设置 › 应用 中卸载 Hushpad。便携版 zip 请先在托盘图标菜单中关闭开机启动，再删除文件夹（Mac 为 Hushpad.app）。无论哪种方式，笔记都会以加密状态保留在仓库文件夹中。如需同时删除笔记，请一并删除仓库文件夹。

Hushpad

安静记录，无人可见。一款不用手动保存、所有笔记都加密存放的 Windows / macOS 记事本。

hush（嘘，安静）+ pad（记事本），意为安静记录的私密记事本。
