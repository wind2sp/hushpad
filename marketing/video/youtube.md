## Description (English)

```
Ever shared your screen with a password note still open?
Hushpad is a notepad built for exactly those notes. It's free and open source.

- There's no Save button. It saves as you type, and on disk every note is AES-256 encrypted.
- On Windows, the Hushpad window doesn't show up in screenshots, screen recordings, or screen shares. Only you see it.
  The Mac build blocks window sharing too, but on macOS 15 and later some screen-sharing apps can still see it.
- Secret notes open hidden, and anything you copy from them is cleared from the clipboard after 30 seconds.
- Ctrl+C keeps formatting. Ctrl+Shift+C copies just the text.
- Keep HTML and JSON in code notes. Ctrl+Alt+J tidies up one-line JSON.
- Drop screenshots (Ctrl+Alt+S) and screen recordings up to 3 minutes (Ctrl+Alt+R) straight into a note.
- From the tray, Ctrl+Alt+M saves whatever's on your clipboard as a note. Ctrl+K searches your notes and commands.

Download: https://gdra.mycafe24.com/hushpad/
Source code: https://github.com/wind2sp/hushpad (GPL-3.0-or-later)

Runs on Windows 10/11 and macOS. The Mac build is for Apple Silicon (M1 or later) only; there's no Intel Mac version.
On Windows there's no installer: unzip it and run. After the first launch it starts with Windows (or opens at login on a Mac); right-click the tray icon to turn that off.
The app speaks English, Korean, Japanese and Simplified Chinese. It starts in your system language, and you can switch under View › Language.
The video shows the Windows version.

0:00 Intro: why there's no Save button
0:16 Hidden from screen capture
0:27 Secret notes, rich or plain copy
0:43 Code notes, screenshots and short recordings
1:00 Hotkeys from the tray, and where to get it

Every note, key, and password in this video is a fake sample. The background music was made in code for this video.

#Hushpad #notepad #privacy #opensource #Windows
```
