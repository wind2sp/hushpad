适用于 Windows / macOS 的记事本

安静记录，无人可见

无需点击保存，输入即记录；所有笔记加密后集中存放在一个文件夹中。窗口不会出现在截图和屏幕共享里。密码、API 密钥、HTML、JSON 乃至截图，都能放在一处。

免费下载 有何不同
版本 1.0.0 · 免费开源（GPL-3.0-or-later）
Windows 10 / 11 · 搭载 Apple 芯片的 Mac · 无需账户 · 无服务器 · 无广告 · 离线运行

如果你也这样用记事本

不保存也能留着的标签页很方便，可一旦越堆越多，就是另一回事了。

“标签页太多，标题都差不多”
用列表、分类和搜索来整理，标签页上还会显示创建时间。单击打开的是预览标签页，随手点开也不会越积越多。
“电脑一关机，内容好像就没了”
边写边安全地存到磁盘，每 10 分钟保留一个历史版本。即使保存途中断电，上一刻的内容也完好无损。
“我把密码和 API 密钥记在记事本里”
所有笔记都只以加密文件的形式保存。机密笔记每次打开都会先遮挡显示，复制的内容 30 秒后会从剪贴板中清除。

轻巧，只做必要的事

像 Windows 记事本一样即开即写，又默默做到记事本做不到的事。

没有保存按钮

输入即自动保存。无需命名，按创建日期和时间自动整理，所有笔记都集中在一个文件夹里。

所有笔记均加密

直接打开文件，也只能看到一堆乱码。其他程序、搜索索引和云服务都读不到内容。

截图拍不到的窗口

截图、录屏和视频会议的屏幕共享都拍不到 Hushpad 窗口，只有你自己看得见。

保留格式，或只要文字

从网页复制的内容连格式一起粘贴，要贴到别处时按 Ctrl+Shift+C 就只复制纯文本。富文本笔记始终附带一份纯文本版本。

HTML、JSON 随手处理

代码笔记带行号、语法着色和自动缩进，JSON 也能马上格式化。在 KEY=值 这样的行上，还能只复制值。

截图与短录屏

随时随地按 Ctrl+Alt+S 区域截图，按 Ctrl+Alt+R 录制屏幕。结果直接放进笔记，视频同样加密。

分类、合并、回收站

拖动即可分类，多条笔记可合并为一条，删除的笔记能从回收站恢复。还能把很久没看的笔记集中整理。

在你的多台电脑上

把存储文件夹放进 Dropbox 或 OneDrive，用同一个密码就能在其他电脑上打开。一条笔记就是一个文件，很少发生冲突。

一个 Ctrl+K 全搞定

在一个输入框里搜索笔记标题、内容和所有功能，按 Enter 即可执行。按 Ctrl+Alt+M 还能直接把剪贴板内容存为笔记。

你的屏幕上看得见，截图里却没有

共享屏幕时开着笔记也好，截图也好，Hushpad 窗口所在的位置都会被后面的画面填上。所以不必挪开窗口，直接截图就行。

  • 截图与录屏工具、视频会议共享在 Windows 上使用系统自带的捕获排除功能（Windows 10 版本 2004 及以上），在 macOS 上关闭窗口共享。
  • 录制时的按钮也不会被录进去录制区域的边框和 ⏸ ⏹ 控制条只显示在你的屏幕上。
  • 需要时可以关闭想特意共享笔记画面时，在菜单里点一下就能关闭。

笔记如何得到保护

Hushpad 没有服务器。笔记只存放在你选定的文件夹里，其中的所有文件都经过加密。

  • AES-256-GCM 加密笔记、历史版本、视频，连分类名称都会加密保存。仅在录屏过程中会临时生成文件，录制结束后立即删除。
  • 由密码派生的密钥（scrypt）不知道密码就无法解密文件。忘记密码的话，连开发者也无法恢复。
  • 在自己的电脑上只需输入一次密钥在 Windows 上与你的账户绑定（DPAPI），在 macOS 上保存在登录钥匙串中。换个账户或换台电脑，就需要重新输入密码。
  • 剪贴板也安安静静复制的内容会加上标记，不会留在 Windows 剪贴板历史记录和云同步中。
  • 无账户、无追踪、无需联网应用和本网站都不使用任何分析或广告脚本。

常见问题

在哪里下载？

在本网站的下载页面获取。文件通过 GitHub Releases 发布，分为 Windows 10 / 11（64 位）版和搭载 Apple 芯片（M1 及更新）的 Mac 版两种。不支持搭载 Intel 处理器的 Mac。

免费吗？开源吗？

都是。Hushpad 免费使用，源代码以 GPL-3.0-or-later 许可证在 GitHub 上公开，任何人都可以查看、修改和再发布。但发布修改版时，需要以相同许可证公开源代码，并改用不同于 Hushpad 的名称和图标。

能把 Windows 记事本里打开的标签页搬过来吗？

可以。在 Windows 版的“菜单 › 文件 › 导入 Windows 记事本标签页”中，连未保存的标签页也能复制过来，Windows 记事本本身不受影响。

忘记密码怎么办？

无法找回。Hushpad 的设计就是不知道密码，任何人（包括开发者）都打不开。首次设置时，请把密码记在安全的地方。

重启电脑后笔记还在吗？

在。笔记一边输入一边加密写入磁盘，重启后依然保留。首次运行后，Hushpad 会在 Windows 启动时（Mac 上为登录时）自动在托盘（Mac 上为菜单栏）中运行。如不需要，可在托盘图标的菜单或“安全”菜单中关闭。

如何在多台电脑上使用？

把存储文件夹放进 Dropbox、OneDrive 等同步文件夹，在另一台电脑上选择同一文件夹并输入相同密码即可。其他电脑上的修改几秒内就会同步过来；如果两边同时修改，会把其中一份另存为“冲突副本”。

可以放入图片或视频吗？

富文本笔记可以粘贴或拖入图片，截图和短录屏（最长 3 分钟）也会直接放进去。视频在应用内播放，并加密保存。

会向网络发送任何数据吗？

不会。Hushpad 没有账户也没有服务器，运行时不会连接互联网。

在 Mac 上也不会被截图拍到吗？

在 macOS 上，Hushpad 通过关闭窗口共享来隐藏窗口。不过在 macOS 15 及以上版本中，部分使用 ScreenCaptureKit 的截图和屏幕共享应用会忽略这一设置，仍可能拍到窗口。在 Mac 上共享屏幕前，请先自行确认。

可以更改应用的界面语言吗？

支持简体中文、英语、日语和韩语，首次启动时跟随系统语言。可随时在“菜单（⋯）› 视图 › 语言”中切换。
