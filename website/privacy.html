한국어

Hushpad는 계정도 서버도 없는 메모장입니다. Hushpad 앱은 사용자가 쓴 내용이나 사용 기록을 인터넷으로 보내지 않습니다. 회사가 사용자 정보를 받아 보관하는 일도 없습니다.

앱이 내 PC에 저장하는 것

  • 메모·이전 버전·스크린샷·녹화·분류 이름: 사용자가 고른 보관 폴더(기본: 문서\Hushpad)에 암호화된 파일(AES-256-GCM)로만 저장합니다. 녹화하는 동안만 임시 파일이 잠깐 생기고, 녹화가 끝나면 지웁니다.
  • 설정과 암호 열쇠: 이 PC의 사용자 폴더에 저장합니다. 암호 열쇠는 Windows DPAPI(macOS는 키체인)로 보호되어 다른 Windows 계정이나 다른 PC에서는 풀 수 없습니다.
  • 백업: 하루 한 번 이 PC 안에 암호화된 상태 그대로 백업합니다.

클립보드와 화면

  • 복사한 내용은 Windows 클립보드 기록·클라우드 클립보드에 남지 않도록 표시합니다. 비밀 메모에서 복사한 내용은 30초 뒤 클립보드에서 지웁니다.
  • 스크린샷과 화면 녹화는 사용자가 직접 실행할 때만 찍고, 메모에 암호화해 저장합니다.

사용자가 동기화 폴더를 고른 경우

보관 폴더를 Dropbox·OneDrive 같은 동기화 폴더에 두면 암호화된 파일이 그 서비스로 올라갑니다. 이때는 해당 서비스의 개인정보 처리방침이 적용됩니다. 파일은 암호화되어 있어 서비스 업체가 내용을 읽을 수 없습니다.

Microsoft Store로 설치한 경우

설치·업데이트 과정에서 Microsoft가 처리하는 정보는 Microsoft의 개인정보 처리방침을 따릅니다.

이 홈페이지

홈페이지는 광고·분석 스크립트와 쿠키를 쓰지 않습니다. 언어 선택은 브라우저 안에만 저장됩니다. 웹 호스팅 서버는 보안을 위해 접속 기록(IP 주소 등)을 일정 기간 남길 수 있습니다. 다운로드 파일은 GitHub에서 제공되며 GitHub의 방침이 적용됩니다.

English

Hushpad is a notepad with no account and no server. The Hushpad app does not send your content or usage data over the internet, and we don't receive or keep any information about you.

What the app stores on your computer

  • Notes, history, screenshots, recordings and category names are stored only as encrypted files (AES-256-GCM) in the vault folder you choose (default: Documents\Hushpad). While a screen recording is in progress a temporary file exists; it is deleted when the recording ends.
  • Settings and the remembered key are stored in your user profile. The key is protected with Windows DPAPI (the Keychain on macOS), so another Windows account or another computer can't unlock it.
  • Backups: once a day, an encrypted copy is kept on the same computer.

Clipboard and screen

  • Copies are marked so Windows clipboard history and cloud clipboard skip them. Text copied from a secret note is cleared from the clipboard after 30 seconds.
  • Screenshots and screen recordings are taken only when you start them, and are stored encrypted in your notes.

If you put the vault in a sync folder

If you choose a folder synced by Dropbox, OneDrive or similar, the encrypted files are uploaded to that service under its privacy policy. Because the files are encrypted, the service can't read your notes.

Installing from the Microsoft Store

Information Microsoft processes during installation and updates is covered by Microsoft's privacy statement.

This website

The website uses no ads, analytics or cookies; your language choice is stored only in your browser. The web host may keep access logs (such as IP addresses) for security for a limited time. Downloads are served by GitHub under GitHub's policies.

日本語

Hushpad はアカウントもサーバーもないメモ帳です。Hushpad アプリは、書いた内容や利用状況をインターネットに送信しません。当社が利用者の情報を受け取って保管することもありません。

  • メモ、履歴、スクリーンショット、録画、分類名は、選んだ保管フォルダー（既定: ドキュメント\Hushpad）に暗号化ファイル（AES-256-GCM）としてのみ保存します。録画中だけ一時ファイルが作られ、録画が終わると削除します。
