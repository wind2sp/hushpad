Windows での初回起動

  1. zip ファイルをダウンロードし、好きな場所（例：ドキュメントフォルダー）に展開します。インストール作業は必要ありません。
  2. 展開した Hushpad フォルダーの Hushpad.exe を実行します。
  3. 「Windows によって PC が保護されました」と表示されたら、「詳細情報 › 実行」をクリックしてください。コード署名をしていない新しいアプリのため、SmartScreen が警告することがあります。気になる場合は、先に下の方法で SHA-256 値を確認してください。
  4. メモを保管するフォルダーとパスワードを決めます。複数の PC で使う場合は、Dropbox や OneDrive 内のフォルダーを選んでください。

Mac での初回起動

  1. zip ファイルをダウンロードして展開し、Hushpad.app を「アプリケーション」フォルダーに移します。
  2. 初回だけは、Finder で Hushpad.app を右クリック（または Control キーを押しながらクリック）して「開く」を選び、警告画面でもう一度「開く」をクリックします。Apple の署名・公証を受けていないアプリのため、ダブルクリックでは開けません。「開く」ボタンが出ない場合は、システム設定 › プライバシーとセキュリティで「このまま開く」をクリックしてください。
  3. 初めてスクリーンショットや画面録画をするとき、macOS が画面収録の許可を求めます。システム設定 › プライバシーとセキュリティの画面収録の項目で Hushpad をオンにし、アプリを再起動してください。
  4. メモを保管するフォルダーとパスワードを決めます。どこからでも使えるショートカットは ⌃⌥N（新規メモ）、⌃⌥M（クリップボードをメモに）、⌃⌥S（スクリーンショット）、⌃⌥R（画面録画）です。

起動時に自動で実行

初回起動のあとは、Windows の起動時（Mac ではログイン時）に Hushpad がトレイ（Mac ではメニューバー）で自動的に起動します。メモは書いたそばから暗号化して保存するので、再起動してもそのまま残ります。自動起動は、トレイ（メニューバー）のアイコンのメニューか［セキュリティ］メニューでオフにできます。

動作環境

  • Windows：Windows 10（バージョン 2004 以降）または Windows 11、64 ビット。キャプチャからウィンドウを隠す機能は Windows 10 バージョン 2004 以降で動作します。
  • Mac：Apple シリコン搭載 Mac（M1 以降）。Intel プロセッサ搭載の Mac 用は提供していません。
  • インターネット接続は不要です。

ファイルの確認（SHA-256）

ダウンロードしたファイルの値を、上の SHA-256 値と比べてください。Windows では PowerShell で Get-FileHash .\Hushpad-win64.zip、Mac ではターミナルで shasum -a 256 Hushpad-macos-arm64.zip を実行します。

アンインストール

自動起動をオンにしている場合は、先にトレイ（メニューバー）のアイコンからオフにしたうえで、プログラムのフォルダー（Mac では Hushpad.app）を削除してください。メモは保管フォルダーにそのまま残ります（暗号化された状態）。メモも消す場合は、保管フォルダーも一緒に削除してください。

Hushpad

静かに書いて、誰にも見せない。保存ボタンなしで自動保存し、すべてのメモを暗号化する Windows・macOS 用メモ帳です。

hush（しーっ、静かに）＋ pad（メモ帳）。静かに書き留めておく、秘密のメモ帳という意味です。
